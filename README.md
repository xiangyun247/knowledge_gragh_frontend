# 忆路康（YiLuKang）前端

> 面向银龄群体的智能认知健康管理平台 · 前端界面

## 项目简介

忆路康前端是「忆路康」智能认知健康管理平台的用户界面，基于 Vue 2 + Element UI 构建，覆盖**智能咨询、认知筛查评估、个性化干预、情感陪伴（小忆）、多角色协同管理**五大核心场景。

核心设计理念：**适老化交互优先**——WCAG ~95% 合规，三主题切换（科技风/医疗风/适老模式），大字号、高对比度、语音输入、TTS 朗读、简化导航，尊重老年用户的使用习惯与人生阅历。

## 功能模块

### 一、智能咨询

| 功能 | 说明 |
|------|------|
| Agent 流式问答 | 对接后端 LangGraph Agent，支持多轮对话、SSE 流式输出、来源溯源（图谱/文献） |
| 深度思考面板 | 可折叠展示 Agent 检索与推理过程 |
| 患者教育 | 一键生成结构化患者教育内容（标题+分节+温馨提示），支持长文/分步/卡片呈现 |
| 科普推文 | 问答结果一键转为 1-3 条科普推文 |
| 多模型选择器 | DeepSeek / GPT / Gemini / 通义 / 豆包 / 智谱 / 文心 / Kimi / Grok |
| 语音输入 | 集成 Whisper，60s 录音限制，自动填入输入框 |
| 图片解读 | OCR + LLM 通俗解释 |
| Markdown 渲染 | 聊天消息支持列表、加粗、引用、表格、代码块排版 |

### 二、认知筛查评估

| 功能 | 说明 |
|------|------|
| 实验测试流程 | 5 步完整流程：信息注册 → 基线问卷 → 系统交互（行为埋点）→ 后测问卷 → 评分报告 |
| NASA-TLX 问卷 | 6 维度 1-7 分 emoji 按钮选择，适老化引导语 |
| 多模态融合评分 | 基于 NASA-TLX 前后测 delta + 行为惩罚（回退+时长），非随机 |
| 趋势分析 | 行为事件与问卷趋势图、来源对比、波动报告 |
| 数据导出 | CSV 导出 + 上传到后端服务器 |

### 三、个性化干预

| 功能 | 说明 |
|------|------|
| 服药提醒 | 用药清单 + 今日任务 + 进度反馈，适老模式大触控目标 |
| 患者教育 | 自适应推荐模式，支持保存与查看历史 |
| 首页日程 | 三件小事 + 今日日程（完成/提醒中/错过/推迟），时间动态调整 |

### 四、情感陪伴（小忆）

| 功能 | 说明 |
|------|------|
| 尊重式对话 | 去除哄小孩语气，尊重老人人生阅历 |
| 记忆面板 | 从对话中提取关键信息，展示老人画像 |
| 情绪指示器 | 动态计算对话情绪状态 |
| TTS 朗读 | 智能选音（优先微软晓晓），全文朗读 |
| 快捷回复 | 常用问题一键发送 |
| 三主题切换 | 科技风 / 医疗风 / 适老模式，持久化 |
| 4 档字号 | 适配不同视力需求 |

### 五、协同管理

| 功能 | 说明 |
|------|------|
| 机构看板 | 管理员/医生聚合统计（事件、用户、问卷、来源分布、趋势图），一键 CSV 导出 |
| 家属周报 | 本周服药/认知状态汇总、活动记录与照护建议 |
| 角色切换 | 个人中心切换角色，老人角色自动启用适老简化模式 |
| SOS 紧急求助 | 紧急联系人维护，一键求助 |

### 六、知识图谱与数据管理

| 功能 | 说明 |
|------|------|
| 知识图谱可视化 | 多图谱切换、实体搜索与筛选、缩放/返回/清除、导出 JSON/图片、图例 |
| 节点详情 | 实体详情展示，支持「问医生」跳转聊天 |
| 文档知识库 | 个人/共享知识库、文献检索、文档列表、基于知识库提问 |
| 数据上传 | 拖拽/选择上传、单文件入库/生成图谱、批量构建、Hadoop 任务状态（云服务器未启用） |
| 模板下载 | 疾病/症状/药物/关系数据模板 |
| 历史记录 | 多类型（问答/搜索/图谱/构建/上传）、筛选、分页、删除 |

### 七、适老化设计

| 特性 | 说明 |
|------|------|
| 三主题系统 | 科技风（深色）/ 医疗风（白蓝）/ 适老模式（高对比+大字号） |
| 老人简化模式 | 角色切换后仅保留四入口导航，路由自动防迷路 |
| 全局语音助手 | 按住说话 → 识别意图（导航/提问）→ 语音反馈 |
| 容错机制 | 危险操作二次确认 + 全局返回条（返回+我在哪） |
| 新手引导 | 适老首次引导，完成任务正反馈 |
| 首次检测 | 网络检测、录音权限提示、破坏性操作播报 |
| WCAG 合规 | ~95% WCAG + 适老化规范 |
| XSS 防护 | DOMPurify 全局过滤 |

## 快速开始

### 环境要求

- Node.js >= 12
- npm >= 6 或 yarn >= 1

### 安装与运行

```bash
npm install
npm run serve      # 开发模式，默认 http://localhost:8080
npm run build      # 生产构建，产物在 dist/
```

### 环境变量

```bash
# 开发环境（.env.development）：本地联调
VUE_APP_API_BASE_URL=http://localhost:5001

# 生产环境（.env.production）：Nginx 同源部署，使用相对路径
VUE_APP_API_BASE_URL=
```

### 与后端联调

1. 启动后端（`python run.py`，端口 5001）
2. 前端 `npm run serve`
3. 确认 `VUE_APP_API_BASE_URL` 指向后端地址
4. 验证登录、问答、图谱、搜索、上传、历史等接口正常

## 主题系统

| 主题 | 风格 | 适用场景 |
|------|------|---------|
| 科技风 | 深色背景、霓虹青蓝与紫色强调 | 默认主题，通用场景 |
| 医疗风 | 白蓝配色、浅色卡片、克制阴影 | 医疗/机构场景 |
| 适老模式 | 高对比度、大字号、大触控目标、减少干扰动效 | 老年用户/简化操作 |

切换方式：顶栏右侧「主题切换」按钮，选择后自动保存到 `localStorage`。老人角色切换时自动启用适老模式。

## 常见问题

| 问题 | 解决方案 |
|------|---------|
| 如何切换主题？ | 顶栏右侧主题切换按钮 |
| 如何进入老人简化模式？ | `/profile` → 角色切换为"老人（简化模式）" |
| 主题切换后图表颜色没变？ | 刷新页面（开发环境 HMR 偶发缓存） |
| 聊天页如何自动带出问题？ | URL 参数 `?question=问题&autoSend=1` |
| 图谱/搜索/历史数据不更新？ | 检查 `VUE_APP_API_BASE_URL` 与后端是否一致 |
| 端口被占用？ | 开发环境自动顺延，以终端输出为准 |

更多问题可查看系统内 **常见问题** 页（`/faq`）。
